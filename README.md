# Сайт «Артфлора»

Интернет-магазин цветов [artflora.by](https://artflora.by): каталог, страница букета, корзина с доставкой и самовывозом, оформление заказа и админка для флористов.

Сделано по макетам «Ягодный сад» (вишня `#7E1F3C`, оливка `#5E6B32`, розовый `#F2C9D4`, белый).

## Что умеет

**Сайт**
- Главная: поводы «Кому дарим?», хиты недели с фильтром по цене, преимущества, подписка на напоминания о датах.
- Каталог: фильтры по поводу, цене, цветку и формату, поиск, пустые состояния.
- Букет: фото, размеры S/M/L со своей ценой, блок «Этот же состав в другом виде», дополнения, текст открытки, примерный расчёт доставки по адресу или району.
- Корзина: на компьютере одной страницей, на телефоне по шагам (Корзина → Доставка → Получатель и оплата). Цены всегда пересчитывает сервер.
- Доставка из ближайшего магазина по зонам 6 / 10 / 14 / 18 BYN, за МКАД +1 BYN за км, бесплатно от 200 BYN, самовывоз −10%.
- Интервалы доставки 10–12 … 18–21, на сегодня — не раньше чем через 2 часа.
- Страница «Заказ принят» и уведомление о заказе в Telegram.

**Админка** (`/admin`, вход по паролю)
- Цветы: только розничная цена и наличие. Меняете цену, и все букеты пересчитываются; справа видно, что изменится на сайте.
- Букеты: состав для каждого размера (цветок × количество) + упаковка, цена считается сама. Нет цветка в наличии → размер или весь букет скрывается и возвращается сам.
- Коллекции: один состав в разных видах (сумка, букет, шляпная коробка, корзина), кнопка «Создать с этим составом».
- Заказы: список, статусы, отметка об оплате.
- Настройки: телефоны и мессенджеры, зоны и цены доставки, магазины, районы, дополнения, реквизиты продавца.

## Как устроено

- [Next.js 15](https://nextjs.org) + TypeScript: сайт и админка в одном приложении.
- PostgreSQL + [Prisma](https://www.prisma.io): схема базы в `prisma/schema.prisma`, деньги хранятся в копейках.
- Расчёты без базы и сети (цены, доставка, интервалы) лежат в `src/lib/pricing.ts`, `delivery.ts`, `slots.ts` и проверяются тестами в `tests/`.
- Адрес → координаты: OpenStreetMap (бесплатно). Для большого потока заказов лучше подключить Яндекс Геокодер.

## Запуск на компьютере разработчика

Нужны Node.js 22 и PostgreSQL 16.

```bash
cp .env.example .env          # впишите пароль админки и SESSION_SECRET
npm install
npx prisma migrate dev        # создаст таблицы
npm run db:seed               # цветы и букеты из макетов
npm run dev                   # сайт на http://localhost:3000, админка на /admin
npm test                      # проверка расчётов
```

## Запуск на сервере

```bash
cp .env.example .env          # ADMIN_PASSWORD, SESSION_SECRET, DB_PASSWORD, SITE_URL
docker compose up -d --build
```

Стартовые цветы и букеты можно залить один раз с компьютера разработчика: `DATABASE_URL=<адрес базы на сервере> npm run db:seed`.

Фото букетов сохраняются в томе `uploads`, база — в томе `db`. Делайте их резервные копии.

## Что ещё не подключено

- Оплата картой и ЕРИП: нужен договор с платёжной системой (например bePaid или Assist). Пока заказ оформляется, а оплату флорист отправляет ссылкой.
- Отправка SMS клиенту.
- Рассылка напоминаний о датах: заявки сохраняются в базе (`Reminder`), отправка — следующий шаг.
