# Заметки для разработки

- Владелец — не программист, общение на русском, объяснять просто.
- Решения владельца: в справочнике цветов только розничная цена и наличие (закупку считает бухгалтерия, в админке её нет). Цена размера = Σ цена цветка × кол-во + упаковка этого размера (у каждого размера своя), автоматически, и округляется вверх до 5 BYN (177 → 180; решение 2026-10-23, `Pricing::roundUpKop`). Нет цветка → размер скрыт; нет ни одного размера → букет скрыт.
- Свадебные букеты (решение 2026-10-28): у букета с поводом «Для невест» галочка «Только в разделе «Свадебные букеты»» (по умолчанию включена, `weddingOnly`) — его нет на главной, в общем каталоге, поиске и других разделах; прямая ссылка, корзина и sitemap работают (`Catalog::general`).
- Замены цветов (решение 2026-10-31): задаются в карточке каждого букета для каждого цветка свои (`bouquet_swaps`, блок «🔁 Замены в этом букете»). Цветок закрыли: есть замена в этом букете и она в наличии → букет на сайте по прежней цене, пометка «🔁 Будет замена» в списке букетов, заказе, письме и Telegram (`order_items.swaps`); замены нет → размер/букет скрыт, даже многосоставной. Замены в справочнике «Цветы» — только подсказка (кнопка в букете); при обновлении они перенесены в букеты, кроме монобукетов.
- Порядок каталога (решение 2026-10-31): Букет дня → ⭐ избранные (`isPinned`) → хиты/эксклюзивы недели → остальные (`Catalog::rank`), внутри группы — ползунки в админке. Новый букет встаёт в конец. Кнопка «🔀 Перемешать остальные» и галочка «каждый день» (настройка `catalog`) мешают только букеты без значков. В списке букетов — «🛒 N за 2 мес.» (заказы).
- Доставка: покупатель выбирает зону цветной кнопкой или точкой на карте; зоны 6/10/14/18 BYN от ближайшего магазина, за МКАД одна цена (по умолчанию 25 BYN, без доплаты за км, бесплатная доставка там не действует), бесплатно от 200 BYN, самовывоз −10%.
- Дизайн берём из макетов «Ягодный сад», ничего не перерисовываем с нуля. Без отзывов на сайте. Корзина на телефоне — по шагам.
- Деньги везде в копейках (Int). Цены от клиента не принимаем: сервер пересчитывает (`src/lib/checkout.ts`).
- Чистая логика: `src/lib/pricing.ts`, `delivery.ts`, `slots.ts`, `money.ts` — покрыта тестами `npm test`.

## PHP-версия (решение владельца 2026-10-23)

На хостинге hoster.by («Стартовый+», ISPmanager) нет Node.js, поэтому в папке `php/` делается вторая версия сайта на PHP 8.1 + MySQL, без Composer. Дизайн и логика повторяют версию на Node.js один в один, правила и разделение работы — `php/README.md`. Тесты: `php php/tests/run.php`. Версия на Node.js + готовый сервер (docker-compose.prod.yml, deploy/) — запасной вариант.
