# Сайт на artflora.by: как поставить на сервер

Простая инструкция для владельца. Где нужно что-то нажать в кабинете hoster.by, написано отдельно.

## Что нужно

- **Облачный сервер (VPS)** на hoster.by: Ubuntu 24.04, 2 ядра, 4 ГБ памяти, 40 ГБ диска, белый IPv4.
  Обычный «Unix-хостинг» не подходит: он для сайтов на PHP, а нашему сайту нужны Node.js и база PostgreSQL.
- Домен artflora.by (уже есть).

## Что где лежит на сервере

| Что | Где |
|---|---|
| Код сайта | `/opt/artflora` |
| Пароли и настройки | `/opt/artflora/.env` (в GitHub не попадает) |
| Резервные копии | `/opt/artflora/backups` (каждый день в 03:00, хранятся 14 дней) |

Снаружи открыты только порты 80 и 443. Сертификат https Caddy получает и продлевает сам (Let's Encrypt).

## Шаги

### 1. Купить сервер (кабинет hoster.by)
Заказать облачный сервер с Ubuntu 24.04. После создания hoster.by показывает **IP-адрес** и **пароль root**.

### 2. Тестовый адрес (кабинет hoster.by → Домены → artflora.by → DNS)
Добавить одну запись, остальные не трогать:

| Тип | Имя | Значение |
|---|---|---|
| A | new | IP сервера |

Старый сайт и почта продолжат работать как раньше.

### 3. Поставить сайт (одна команда)
Войти на сервер. На Windows: «Пуск» → «Терминал», команда `ssh root@IP-сервера`, затем пароль root.
Вставить:

```bash
curl -fsSL https://raw.githubusercontent.com/dinx393/artflora-site-/refs/heads/claude/project-thread-b45kuf/deploy/setup-server.sh | bash -s -- new.artflora.by
```

Через 5–10 минут команда напишет «Готово» и **пароль админки**. Запишите его.
Сайт откроется на https://new.artflora.by, админка на https://new.artflora.by/admin.

### 4. Почта о заказах
`nano /opt/artflora/.env`: вписать `SMTP_USER` и `SMTP_PASS` (пароль приложения Gmail, см. главный README).
Сохранить (Ctrl+O, Enter, Ctrl+X), затем `cd /opt/artflora && docker compose up -d`.
После этого: админка → «Настройки» → «Отправить пробное письмо».

### 5. Наполнить и проверить
Завести цветы и букеты в админке. Оформить пробный заказ (доставка и самовывоз).

### 6. Переезд на artflora.by
1. В `/opt/artflora/.env` поменять `DOMAIN=artflora.by` и `SITE_URL=https://artflora.by`, затем `docker compose up -d`.
2. В DNS artflora.by: записи **A для `@` и `www`** указать на IP сервера.
   **Записи MX, TXT (SPF/DKIM) и `mail` не трогать**, иначе перестанет работать почта zakaz@artflora.by.
3. В течение 1–2 часов DNS обновится везде, и Caddy сам получит сертификат.
4. Старый хостинг не отключайте ещё пару недель. Почта и файлы старого сайта остаются там.

## Каждый день

| Что сделать | Команда (на сервере, в `/opt/artflora`) |
|---|---|
| Обновить сайт после новых коммитов | `git pull && docker compose up -d --build` |
| Посмотреть, что пишет сайт | `docker compose logs -f site` |
| Сделать копию прямо сейчас | `docker compose exec backup sh /backup.sh now` |
| Список копий | `ls backups` |
| Восстановить из копии | `sh deploy/restore.sh 2026-11-01_0300` |
| Скачать копии к себе на компьютер | на своём компьютере: `scp -r root@IP-сервера:/opt/artflora/backups .` |

Копии лежат на том же сервере. Поэтому раз в неделю скачивайте их к себе или включите платные «резервные копии/снапшоты» сервера в hoster.by.

## Защита админки

- Вход только по https, пароль от 12 символов (сайт не запустится со слабым паролем).
- После 5 неверных паролей за 15 минут вход с этого адреса блокируется.
- Админка закрыта от поисковиков (`robots.txt`).
- Сменить пароль: поменять `ADMIN_PASSWORD` в `.env`, затем `docker compose up -d`.
